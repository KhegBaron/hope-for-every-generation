# Hope for Every Generation Foundation Website

Static website (HTML, CSS, JavaScript). No build step is needed.

## Pages
- `index.html` Home
- `about.html` About
- `leadership.html` Leadership (currently shows "Coming Soon")
- `collaboration.html` Collaboration
- `give.html` Ways to Give (online donations currently show "Coming Soon")
- `404.html` Page not found

## Updating later
- **Online donations:** open `give.html` and find the comment that starts with `ONLINE DONATIONS`. Follow the three steps there.
- **Leadership team:** open `leadership.html` and find the comment that starts with `LEADERSHIP PROFILES`. Replace the "Coming Soon" block with the card grid and fill in each person.
- **Phone number:** if you want one listed, add it to the Contact list in the footer of each page and to the Reach Us section of `give.html`.

## Domain
The SEO tags, `sitemap.xml`, and `robots.txt` use `https://www.hopeforeverygeneration.org`.
If the site is published at a different address, replace that address in every `.html` file, `sitemap.xml`, and `robots.txt`.
After launch, submit `sitemap.xml` in Google Search Console.
